  nodejs

    express
- ### SGBD :

  Handlebars
- ### Langages :
    Javascript
    
    HTML5 / CSS3

# Lancement :
Cloner le projet avec la commande :
```bash
git clone git@github.com:Dragon-de-rage/Festival.git
```
Puis, dans le dossier du projet :
```bash
npm start
```
L'application tourne maintenant à l'adresse : [localhost:8080](http://localhost:8080/)
